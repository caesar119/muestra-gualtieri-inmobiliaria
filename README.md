# muestra-gualtieri-inmobiliaria

Muestra de una sola pantalla para un prospecto real (Gualtieri Inmobiliaria, Neuquén
Capital), hecha por **Anett Digital** con Astro + Tailwind. No es el sitio oficial
de Gualtieri Inmobiliaria — ver el aviso en la propia página.

- Publicado en GitHub Pages: https://caesar119.github.io/muestra-gualtieri-inmobiliaria/
- `noindex, nofollow` a propósito (meta robots + `robots.txt`): no debe indexarse.
- Build para la raiz de un dominio: `npm ci && npm run build`
- Build para una subcarpeta: `ASTRO_BASE=/muestra-gualtieri-inmobiliaria npm run build`

Sin logo ni colores de marca reales de Gualtieri (no los mandaron todavía): paleta
sobria y neutra. Ver el comentario de entrega en la tarea de Paperclip para el
detalle de qué cambia cuando lleguen el logo, los colores y las fotos reales.
